# Smart Door Locks media

Used by `app/components/catalog/DoorLockStory.tsx`. All generated (illustrative) with Higgsfield, 2026-11-28.

- `hero-asleep.webp`, `hero-awake.webp`: the hero, the Smart Wooden Door Lock on a walnut front door at night, unlit and lit. Scroll crossfades them, so the lock "wakes".
  - GPT Image 2.6 (high, 2K, 16:9). References: Heseos's own SS304 product artwork (for the panel and the HESEOS logo under the keypad) and the site's night door photo. A second edit removed the steel mortise faceplate, which sits inside the door edge and isn't visible on a fitted lock. The lit frame is an edit of that one with the same camera; only the keypad backlight and the blue fingerprint ring change.
  - Lever points left, toward the hinges, and the lock sits at the door's opening edge beside the frame.
  - Saved at 2400 px wide, WebP q82.
- `coming-home.mp4`, `coming-home-720.mp4`, `coming-home-poster.webp`, `coming-home-end.webp`: the "Coming home" film. A woman touches the fingerprint sensor, presses the lever and walks in.
  - Start frame: GPT Image 2.6 (high, 2K, 16:9) from the site's entrance photo (`/media/catalog/wooden-door-lock/wooden-door-lock-wooden-entrance.webp`). End frame: an edit of the start frame with the same camera.
  - Door physics: the lock is on the door's LEFT (opening) edge with the lever pointing right toward the hinges, which are on the RIGHT edge. The door swings inward, away from her. Checked frame by frame. (The earlier film had the lock on the hinge side, so the door seemed to open the wrong way.)
  - Film: Kling 3.0 Pro, 5 s, sound off, start and end frames, static camera. Scrub encoding: H.264, a keyframe every 4 frames, no B-frames, faststart, no audio; 1920×1080 CRF 21 and 1280×720 CRF 22. `coming-home-poster.webp` is the first frame and `coming-home-end.webp` the last, shown with reduced motion.
- `hero.webp`, `entrance-away.webp`, `entrance-home.webp`: older stills, not used on the page.
- The "Seven ways in" section uses the studio shot `/media/products/studio/wooden-door-lock.webp`. The guests section uses `/media/catalog/wooden-door-lock/wooden-door-lock-wooden-app.webp`.
